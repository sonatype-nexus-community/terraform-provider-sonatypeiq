# sonatypeiq_global_role_membership (Resource)

Use this resource to grant a global role, such as System Administrator, to a user or a group. Global roles can only be granted globally: use `sonatypeiq_organization_role_membership` or `sonatypeiq_application_role_membership` for any other role. Requires the _Edit System Configuration and Users_ permission.

~> **Warning** Destroying or replacing this resource revokes the role. If it grants the System Administrator role to the user that this provider connects as, that user loses its administrator access and Terraform can no longer manage Sonatype IQ Server.

## Example Usage

```terraform
# Look up a global role, such as System Administrator
data "sonatypeiq_role" "system_administrator" {
  name = "System Administrator"
}

# Grant it to a group (for example one provided by your SSO) ...
resource "sonatypeiq_global_role_membership" "admin_group" {
  role_id    = data.sonatypeiq_role.system_administrator.id
  group_name = "My Admin Group"
}

# ... or to a user
resource "sonatypeiq_global_role_membership" "admin_user" {
  role_id   = data.sonatypeiq_role.system_administrator.id
  user_name = "jane.doe"
}
```
